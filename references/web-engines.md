# Web engines — 网页端引擎手册（浏览器驱动，默认优先）

**图片分析默认走网页端引擎**：由智能体用**浏览器自动化**直接操作网页版多模态
模型——打开站点 → 上传图片 → 发送问题 → 读取回复。免费、无需注册 API key，
**优先于所有 API 引擎**。仅当当前环境没有浏览器能力、或全部网页端站点额度
耗尽时，才回退到 API 引擎（GLM/Qwen/SiliconFlow/Gemini/MinerU/local）。

> 额度说明：所有网页端的免费额度（尤其未登录态）都由厂商动态调整，下面表格中的
> 次数是常见参考值，**以页面上的实际提示为准**。遇到「今日次数已用完 / 已达上限 /
> 请登录后继续」等提示，即视为该站点额度耗尽。

## 核心规则

1. **默认优先**：图片分析先走网页端引擎（浏览器），API 引擎是回退路径。
2. **登录态 = 无限续杯**：若浏览器已登录该站点，直接使用，不设次数上限，
   可一直用同一站点完成所有请求。
3. **未登录 = 限额轮换**：每站免费次数用完（页面出现额度提示）后，关闭该站点
   换下一个，直到全部站点耗尽。
4. **全部耗尽**：回退到 API 引擎链（`glm → qwen → siliconflow → gemini →
   mineru → local`）；若 API 也无可用 key，则报告「所有网页端模型今日免费额度
   已用完」，建议用户登录任一站点（或提供 API key），明天 0 点额度重置后再来。
5. 一次只操作一个站点，成功拿到结果就停止，不要并行占用多个站点。

## 使用流程（浏览器操作 SOP）

准备：先把图片压缩到 < 4MB（`vision.py` 会帮你处理，或直接用已保存的本地图片路径）。

1. **打开站点**：访问上表 URL（优先用无痕/普通窗口均可，无需清理 Cookie）。
2. **判定登录态**：
   - 页面右上角/侧边栏有「头像 / 我的 / 账号」→ 已登录；
   - 有明显「登录 / 扫码登录」按钮 → 未登录。
3. **上传图片**：点击聊天输入框的「+ / 回形针 / 图片」按钮 → 选择本地图片文件。
4. **输入问题**：在输入框写入用户的原始问题（原样传入，如「这张截图里有什么错误？」）。
5. **发送并等待**：回车或点发送，等待流式回复**完全结束**（「停止生成」按钮消失
   或回复区不再变化）。
6. **读取回复**：抓取回复区的完整文本。
7. **额度检查**：若出现以下任一提示 → 关闭当前站点，跳到清单下一站重试：
   - 「今日次数已用完 / 今日额度已用完 / 已达上限」
   - 「请登录后继续使用」
   - 「开通会员 / 升级 Pro」引导弹窗
8. **收尾**：得到结果后关闭多余标签页，避免留下大量会话占用额度。

## 失败处理

| 情况 | 处理 |
|---|---|
| 站点打不开 / 超时 | 跳过，换下一站 |
| 出现验证码 / 人机验证 | 跳过，换下一站（不要尝试自动破解） |
| 上传被拒（格式/大小） | 压缩或转 JPG/PNG 后重试；再失败则换站 |
| 回复为空 / 仅生成图片 | 视为失败，换下一站 |
| 用户已登录但报错 | 换登录状态下可用的下一站，或报告错误详情 |

## 注意事项

- 图片上传前建议压缩（长边 ≤ 2048px、≤ 4MB），避免站点限制，也加快上传。
- 提示词要明确、可操作：OCR 用「请逐字提取图中文字，标注不确定处」；
  截图分析用「请描述图中界面状态、错误信息、选中项」；图表用「列出可见标签与数值」。
- 不要复制、导出或保存任何站点的 Cookie / 登录凭证；已登录会话属于用户，用完即走。
- 未登录轮换时，浏览器会话残留的登录态可能变化，每次使用前重新判定登录态。
- 该引擎由智能体浏览器操作完成，`vision.py` 在选中 web 引擎时输出**浏览器操作
  引导**（图片路径 + prompt + 站点轮换说明），由智能体接棒执行；它是图片分析的
  **默认首选**路径，API 引擎为回退。
